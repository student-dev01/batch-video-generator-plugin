# 批量视频生成插件 · 开源版

> 开源版本 · 2026-11-21 · MIT 协议
> 由 Muse 适配的版本：输入一句话故事，批量产出多镜头、风格统一的短片。

## 开源协议

MIT License —— 可以自由使用、修改、分发，包括商用，只需保留这份协议和原作者说明。

## 它是做什么的

一句话故事 → 分镜规划 → 风格锁定 → 尾帧接力逐镜生成 → 抽卡打分选片 → 质检重抽 → 拼接成片。

工作台里走完这个流程，视频生成在 Muse 里完成（每段约 10 秒，每轮最多 6 条候选视频）。

## 工作流程

1. 建项目：填一句话故事、人物、场景、风格，镜头数默认 5。
2. 拆分镜：自动拆成 N 个 10 秒镜头，或手动逐镜编辑。每镜含运镜、画面、对白（可空）、尾帧状态。
3. 风格锁定：人物 / 场景 / 风格三项固化，拼装规则逐字固定：
   ```
   每条镜头提示词 = 锁定段（人物 + 场景 + 风格，逐字固定）+ 镜头段（本镜运镜 / 画面 / 对白 / 尾帧）
   ```
4. 分批生成：第 1 轮镜头 1–2（6 条）、第 2 轮镜头 3–4（6 条）、第 3 轮镜头 5（3 条）。每轮在工作台一键复制整批提示词，去「生成视频」会话生成。
5. 尾帧接力：第 i 镜用第 i-1 镜成片的真实末帧做参考，首帧承接上一镜尾帧的人物姿态、位置、光线与物体状态。
6. 打分选片：每镜 3 候选，连续性 60% + 真实感 40%，同分连续性优先。
7. 质检闸门：时长、接缝、跳切、换脸四项；不合格自动重抽，最多重抽 2 次，仍不合格转人工，不阻塞其他镜头。
8. 拼接成片：通过质检的镜头按序拼接，整体复检接缝后导出。5 镜成片约 50 秒。

## 画幅

- 横屏 16:9，1280×720（默认）
- 竖屏 9:16，720×1280

## 内置示例：晨光面包房（通用模板，不含任何私人素材）

人物：年轻面包师，白色围裙，头发利落，神情专注。
场景：清晨小城面包房、揉面台、烤箱、街角、傍晚收摊。
风格：暖黄色调，自然光，35mm 胶片质感，轻微颗粒。
5 镜：清晨开门 → 揉面备料 → 烤箱出炉 → 街角送面包 → 傍晚收摊背影。

## V1 不做的事

- 不直接套版权歌曲，不做指定人声配音；声音氛围只能写在提示词里
- 不做复杂剪辑、转场特效、字幕样式（字幕靠后期）
- 不自动发布到抖音
- 不承诺人物 100% 不变，只做“锁定段 + 尾帧接力 + 打分 + 重抽”

## 复现包

工作台「导出复现包」可一键复制或下载 .md 文件，含按轮打包的全片提示词包、分镜表和每条候选的选片结果，拿到就能在自己的 Muse 里复现。

## 注意事项

- 本开源版只包含流程、规则、提示词模板和通用示例，不含任何个人视频、人物定妆照和私人素材。
- 视频生成、拼接需要你自己的 Muse 账号和 FFmpeg / 剪映等后期工具完成。
