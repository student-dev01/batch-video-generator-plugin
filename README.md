# 批量视频生成插件 · 开源版

> 开源版本 · 2026-11-21 · MIT 协议
> 2026-11-24 更新：去掉平台专属表述，任何 AI 都能用。
> 输入一句话故事，批量产出多镜头、风格统一的短片。

## 任何 AI 都能用

这个插件不是某个 AI 专属的，它就是一套文字写成的工作流：规则 + 提示词模板。

只要你用的 AI 能按提示词生成视频（ChatGPT / Sora、豆包 / 即梦、可灵、Runway，或任何支持“文字提示词 + 参考图 → 视频片段”的工具），就能跑完整套流程：把下面“工作流程”那几步直接发给你的 AI，让它按步骤执行；或者照着步骤手动操作。

视频片段的时长、每轮能出几条候选，看你用的工具支持多少——流程本身不变。

## 它是做什么的

一句话故事 → 分镜规划 → 风格锁定 → 尾帧接力逐镜生成 → 抽卡打分选片 → 质检重抽 → 拼接成片。

## 工作流程

1. 建项目：填一句话故事、人物、场景、风格，镜头数默认 5。
2. 拆分镜：拆成 N 个 10 秒镜头，或手动逐镜编辑。每镜含运镜、画面、对白（可空）、尾帧状态。
3. 风格锁定：人物 / 场景 / 风格三项固化，拼装规则逐字固定：
   ```
   每条镜头提示词 = 锁定段（人物 + 场景 + 风格，逐字固定）+ 镜头段（本镜运镜 / 画面 / 对白 / 尾帧）
   ```
4. 分批生成：第 1 轮镜头 1–2（6 条）、第 2 轮镜头 3–4（6 条）、第 3 轮镜头 5（3 条）。每轮复制整批提示词，去你的 AI 视频工具里生成。
5. 尾帧接力：第 i 镜用第 i-1 镜成片的真实末帧做参考，首帧承接上一镜尾帧的人物姿态、位置、光线与物体状态。
6. 打分选片：每镜 3 候选，连续性 60% + 真实感 40%，同分连续性优先。
7. 质检闸门：时长、接缝、跳切、换脸四项；不合格重抽，最多重抽 2 次，仍不合格转人工，不阻塞其他镜头。
8. 拼接成片：通过质检的镜头按序拼接，整体复检接缝后导出。5 镜成片约 50 秒。

## 画幅

- 横屏 16:9，1280×720（默认）
- 竖屏 9:16，720×1280

## 内置示例：晨光面包房（通用模板，不含任何私人素材）

人物：年轻面包师，白色围裙，头发利落，神情专注。
场景：清晨小城面包房、揉面台、烤箱、街角、傍晚收摊。
风格：暖黄色调，自然光，35mm 胶片质感，轻微颗粒。
5 镜：清晨开门 → 揉面备料 → 烤箱出炉 → 街角送面包 → 傍晚收摊背影。

## V1 不做的事

- 不直接套版权歌曲，不做指定人声配音；声音氛围只能写在提示词里
- 不做复杂剪辑、转场特效、字幕样式（字幕靠后期）
- 不自动发布到抖音
- 不承诺人物 100% 不变，只做“锁定段 + 尾帧接力 + 打分 + 重抽”

## 复现包

按轮打包的全片提示词包、分镜表和每条候选的选片结果，存成一个 .md 文件，拿到就能在任何支持提示词 + 参考图的 AI 视频工具里复现。

## 注意事项

- 本开源版只包含流程、规则、提示词模板和通用示例，不含任何个人视频、人物定妆照和私人素材。
- 视频生成需要你自己的 AI 视频工具账号，拼接用 FFmpeg / 剪映等后期工具完成。
